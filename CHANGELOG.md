# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2026-05-17

### Added
- Professional documentation suite using MkDocs and Material theme.
- Read the Docs integration.
- Standardized API reference.
- Enhanced plotting capabilities (18+ plot types).
- Automated Markdown reporting.
- Interactive Jupyter what-if widget.
- Support for 5 different WOE methods.
- Built-in feature selection tools (IV-based and correlation).

### Changed
- Complete refactor to be fully scikit-learn compatible.
- Modernized API with `BinningTransformer`, `WOETransformer`, and `ScoreCardTransformer`.
- Switched to `hatchling` as build backend.

## [1.0.0] - 2024-01-10

### Added
- Initial release with basic binning and WOE functionality.
- Support for Logistic Regression scorecards.
